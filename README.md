# One-Liner Laugh Lab

One short funny line answering a prompt — the excuse a robot vacuum
gives after eating a sock — written to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```

Deterministic: the same single line every run, no input, no network,
no randomness. The line is 1–200 UTF-8 characters, one line, not only
whitespace.
